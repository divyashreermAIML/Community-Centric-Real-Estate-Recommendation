# Community-Centric Real Estate Recommendation and Decision Support System

## Project Overview
This project aims to develop a community-centric real estate recommendation and decision support system that helps users identify suitable properties based on their preferences, budget, location, amenities and community requirements.

## Objectives
- Recommend suitable properties based on user preferences.
- Support different real estate categories.
- Provide student PG and hostel recommendations.
- Compare properties using a suitability score.
- Improve property selection through explainable recommendations.

## Proposed Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Data Processing: Pandas, NumPy
- Dataset: CSV / Database
- Visualization: Chart.js / Plotly
