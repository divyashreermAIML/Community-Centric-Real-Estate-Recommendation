# Project Overview

## Project Title
Community-Centric Real Estate Recommendation and Decision Support System

## Problem Statement
Finding suitable properties based on budget, location,
amenities and community requirements can be difficult.

## Proposed Solution
A recommendation system that helps users compare
and identify suitable properties.
